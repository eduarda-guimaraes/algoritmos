## 🇧🇷 Português

Repositório dedicado aos meus estudos e exercícios de **Algoritmos**, desenvolvidos em **Java** durante as aulas da graduação em Sistemas de Informação.

O objetivo é praticar a lógica de programação, desenvolver o raciocínio computacional e consolidar os fundamentos da linguagem Java.

## Conteúdos

Os exercícios estão organizados em pastas dentro de `src/`, seguindo a estrutura utilizada durante as aulas.

- ☕ **Fundamentos de Java** — sintaxe, variáveis e entrada de dados.
- 🧩 **Lógica de programação** — estruturas condicionais e de repetição.
- 📦 **Vetores e matrizes** — manipulação de arrays e estruturas multidimensionais.
- 📝 **Exercícios e atividades** — práticas desenvolvidas em aula.

### Como executar

1. Abra o projeto no [IntelliJ IDEA](https://www.jetbrains.com/idea/) ou no Eclipse.
2. Navegue até a pasta `src/` e localize a classe desejada.
3. Execute a classe que contém o método `main`.
4. Se solicitado, informe os valores pelo terminal.

## 🇺🇸 English

A repository dedicated to my **Algorithms** studies and exercises, written in **Java** during my Information Systems degree.

The goal is to practice programming logic, develop computational thinking, and strengthen my understanding of Java fundamentals.

## Topics

The exercises are organized into folders under `src/`, following the structure used during classes.

- ☕ **Java Fundamentals** — syntax, variables, and user input.
- 🧩 **Programming Logic** — conditional and looping structures.
- 📦 **Arrays and Matrices** — array manipulation and multidimensional structures.
- 📝 **Exercises and Assignments** — practical activities completed in class.

### How to Run

1. Open the project in [IntelliJ IDEA](https://www.jetbrains.com/idea/) or Eclipse.
2. Navigate to `src/` and locate the desired class.
3. Run the class containing the `main` method.
4. If prompted, enter the required values in the terminal.
